# Автотесты интернет-магазина EXIST.RU

Smoke-автотесты для сайта [exist.ru](https://www.exist.ru/): открытие сайта, регистрация, авторизация,
гараж, каталоги, поиск, корзина. Дипломная работа по курсу «Автоматизация тестирования Python»
(Академия ТОП, Уфа).

**Стек:** Python, Pytest, Playwright (sync API), Allure.

## Что проверяют тесты

| Тест | Что проверяет |
|---|---|
| `test_site_opening` | Открытие главной страницы, адрес и заголовок |
| `test_registration` | Форма регистрации заполняется, кнопка «Зарегистрироваться» доступна |
| `test_login` | Вход в аккаунт |
| `test_login_invalid` | Вход с неправильным логином и паролем: появляется ошибка, вход не выполнен |
| `test_garage_add_car` | Добавление ТС в гараж по VIN, проверка названия |
| `test_requested_article` | Оригинальный каталог → цены → запрошенный артикул |
| `test_garage_remove_car` | Удаление ТС из гаража |
| `test_catalog_by_oil` | Каталог → моторные масла |
| `test_oil_search` | Поиск масла через строку поиска |
| `test_vin_search` | Поиск по VIN и переход к маслам для машины |
| `test_catalog_navigation` | Навигация по каталогу BMW |
| `test_order_submission` | Добавление товара в корзину и удаление |

## Структура проекта

```
exist-ru-autotests/
├── Test/
│   ├── test_login.py          # автотесты
│   ├── login_actions.py       # вход на сайт, закрытие окна выбора региона
│   └── auth.example.json      # шаблон файла с логином и паролем
├── conftest.py                # после тестов строит и открывает отчёт Allure
├── pytest.ini                 # настройки запуска и папка результатов Allure
├── requirements.txt           # Python-зависимости
└── .gitignore
```

## Установка

1. Установить Python 3.11+ и [Allure Commandline](https://allurereport.org/docs/install/) (нужна Java).
   Проверить: `allure --version`.
2. Создать виртуальное окружение и установить зависимости:

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux / macOS
pip install -r requirements.txt
playwright install chromium
```

3. Создать файл `Test/auth.json` по образцу `Test/auth.example.json` и вписать свой логин и пароль
   от exist.ru. Файл `auth.json` добавлен в `.gitignore`: **не публикуйте его в репозитории**.

```json
{
    "login": "ваш_логин",
    "password": "ваш_пароль"
}
```

## Запуск

Все тесты. После прогона автоматически строится отчёт Allure и открывается в браузере:

```bash
pytest
```

Один тест:

```bash
pytest Test/test_login.py::test_login
```

Результаты сохраняются в `allure-results/`, готовый HTML-отчёт - в `allure-report/`.
Если отчёт не открылся, проверьте, что команда `allure` доступна в терминале.

## Важно

- Тесты работают с реальным сайтом и реальным аккаунтом. Тесты гаража добавляют и удаляют ТС
  в вашем гараже, поэтому запускайте их на тестовом аккаунте.
- Тесты гаража зависят друг от друга: удаление и поиск артикула ожидают, что машина из
  `test_garage_add_car` уже есть в гараже. Запускайте их в порядке, в котором они идут в файле.
- Вёрстка сайта может меняться: если тест упал на локаторе, проверьте его актуальность.
